# Память (общие правила)

## ПРАВИЛО: "ЗАПОМНИ" = ЗАПИСЬ В ФАЙЛ

**Когда пользователь говорит "запомни" — ОБЯЗАТЕЛЬНО записать информацию в файл** (например, `MEMORY.md` или другой подходящий файл заметок). Не отговариваться, не просто подтверждать словами — сохранять на диск.

## ПРАВИЛО: GIT — СМОТРИ `GIT_NOTES.md`

При любой работе с git первым делом читать и соблюдать `GIT_NOTES.md`.
