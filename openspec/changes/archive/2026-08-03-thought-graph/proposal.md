## Why

Существующие инструменты для заметок разделяют два режима мышления: либо линейные документы (Joplin, Notion), либо плоские доски (Miro, tldraw). Нет системы, которая сочетает частый граф лёгких мыслей (как TheBrain) с семантической векторной сетью, оставаясь при этом локальной, приватной и открытой по данным. Пользователь не знает заранее, как будет думать о материале через неделю — нужна органика пространства, а не жёсткая таксономия.

## What Changes

- Создаётся локальное SPA-приложение (без сервера) с 2D-графом лёгких карточек-мыслей.
- Навигация по графу — «плекс»: радиальное облако связей вокруг текущей мысли, перескоки по связям (модель TheBrain).
- Вводится подсвеченная семантическая сеть: вокруг текущей мысли серым пунктиром показываются семантически близкие карточки (мягкие связи), не меняя ручную раскладку.
- Архитектура — переносимый core (чистый домен) с API-контрактом, отделённый от адаптеров окружения (хранение, эмбеддинги).
- В браузере: хранение в IndexedDB, эмбеддинги через transformers.js (WASM/WebGPU).
- Письмо (полноценные документы) — отдельный слой, ссылающийся на карточки, но не являющийся узлами графа.
- Core спроектирован так, чтобы позже его можно было вынести на Node.js-сервер (файлы + SQLite, onnxruntime-node, HTTP API) без переписывания домена.

## Capabilities

### New Capabilities
- `thought-graph`: граф лёгких карточек-мыслей с плекс-навигацией, ручными (жёсткими) связями и CRUD карточек.
- `semantic-links`: подсвеченная семантическая сеть — генерация эмбеддингов, векторный поиск, мягкие связи вокруг текущей мысли.
- `portable-core`: переносимый core-модуль с чистым доменом и API-контрактом, отделённый от адаптеров окружения.
- `writing-layer`: отдельный слой полноценных документов, ссылающихся на карточки графа.

## Impact

- **Код**: новый проект SPA (TypeScript). Модули: core (домен), адаптеры браузера (IndexedDB, transformers.js), UI (2D-граф).
- **API**: core-контракт (порты) — карточки, связи, плекс, семантический поиск, предложение связей.
- **Зависимости**: transformers.js (эмбеддинги), библиотека графов/канвас для 2D-рендера, IndexedDB-обёртка.
- **Данные**: карточки и связи сериализуются в IndexedDB; формат спроектирован так, чтобы позже переноситься на файлы + SQLite.
- **Системы**: без сервера, оффлайн, приватно. Будущее — вынос core на Node без изменения домена.
