## Purpose

Добавляет подсвеченную семантическую сеть поверх графа: система генерирует векторные эмбеддинги карточек и показывает мягкие связи между семантически близкими мыслями, не меняя ручную раскладку.

## Requirements

### Requirement: Генерация эмбеддингов карточек
Система SHALL генерировать векторный эмбеддинг для каждой карточки на основе её заголовка и тела. Эмбеддинг SHALL обновляться при изменении содержимого карточки.

#### Scenario: Генерация при создании
- **WHEN** создаётся новая карточка
- **THEN** система генерирует её эмбеддинг и сохраняет его

#### Scenario: Обновление при редактировании
- **WHEN** пользователь изменяет содержимое карточки
- **THEN** система пересчитывает и сохраняет её эмбеддинг

### Requirement: Подсветка семантически близких карточек
Система SHALL отображать вокруг текущей карточки мягкие связи (серым пунктиром) к семантически близким карточкам, которые не связаны с ней жёсткой ручной связью. Мягкие связи SHALL не изменять ручную раскладку графа.

#### Scenario: Отображение мягких связей
- **WHEN** пользователь выбирает карточку, у которой есть семантически близкие карточки без жёсткой связи
- **THEN** система отображает эти карточки с мягкой связью серым пунктиром

#### Scenario: Отсутствие мягких связей
- **WHEN** пользователь выбирает карточку, у которой нет семантически близких карточек
- **THEN** система не отображает мягких связей

### Requirement: Семантический поиск
Система SHALL позволять пользователю искать карточки по семантической близости к произвольному текстовому запросу, а не только по точному совпадению слов.

#### Scenario: Семантический поиск по запросу
- **WHEN** пользователь вводит семантический поисковый запрос
- **THEN** система возвращает карточки, ранжированные по косинусной близости их эмбеддингов к эмбеддингу запроса

### Requirement: Предложение жёстких связей
Система SHALL предлагать пользователю превратить мягкую связь в жёсткую ручную связь, когда две карточки семантически близки.

#### Scenario: Предложение связи
- **WHEN** система обнаруживает две семантически близкие карточки без жёсткой связи
- **THEN** система предлагает пользователю создать между ними жёсткую связь

#### Scenario: Принятие предложения
- **WHEN** пользователь принимает предложение о создании жёсткой связи
- **THEN** система создаёт жёсткую связь между карточками, и мягкая связь исчезает
